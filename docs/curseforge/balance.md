# Folkhold Balance

## Summary

A limit for the fast nights of the Slumber mod: each server tick stays short while the players sleep.

## Description

**Folkhold Balance limits the fast nights of the Slumber mod.** It works alone: it needs no other Folkhold mod.

### Fast nights (with Slumber)

- With the Slumber mod, the night goes fast when all the players sleep. The game runs the ticks of the night: the furnaces smelt and the crops grow.
- Folkhold Balance limits the extra ticks in each server tick, so that each server tick stays short.
- A clock keeps the night at about 40 seconds of real time (option `nightSeconds`). In a slow world, the time jumps ahead in small steps.

The options are in the configuration of the mod.

### Trains, trades and enchantments

These features are in separate mods:

- **Railhold:** trains of linked minecarts, locomotives and storage minecarts. A world with the trains of Folkhold Balance opens with Railhold and keeps its trains.
- **Markethold:** no Mending in trades and in fishing.
- **Runehold:** an anvil with no level cap.

The Folkhold modpack has these three mods.

### Requirements

- Minecraft 1.21.1, NeoForge 21.1.259 or later, Java 21.
- Optional mod: Slumber (fast nights). With no Slumber, the mod has no effect.
- Client and server.
